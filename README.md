## Option 1 :  Instructions for Github clone

1. **Clone the repository**  
    ```bash
    git clone <repository-url>
    ```
2. **See Step 3 onwards**
## Option 2 :  Download and unzip project folder

1. **Select “Extract All” and extract the contents completely**
   
2. **Open terrminal and navigate inside the project folder**
   ```bash
    cd Orbital-Frontend
    ```

3. **Install the required Node modules**  
    ```bash
    npm install
    ```

4. **Run the development server**  
    ```bash
    npm run dev
    ```
5. **Open your browser and visit:**
   ```bash
    http://localhost:8081
    ```
6. **To run unit testing, open another terminal and run**  
    ```bash
    npm test
    ```
7. **For backend setup**  
   Please refer to the backend repository’s README for further instructions.
